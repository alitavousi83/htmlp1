فایل‌های Markdown با پسوند .md نوشته می‌شوند و  
ابزاری ساده و قدرتمند برای نوشتن متن‌های ساختاریافته  
مانند مستندات، یادداشت‌ها یا صفحات وب هستند.  
در Markdown می‌توانید فقط با چند نشانه‌گذاری اولیه  
متنی داشته باشید که به راحتی خوانده شود و  
قابلیت نمایش به صورت حرفه‌ای در نرم‌افزارهای مختلف را دارد.

برای شروع کار با فایل‌های مارک‌داون، یک فایل متنی  
با پسوند .md بسازید و آن را با هر ویرایشگر متنی  
(مانند Notepad، VS Code یا Atom) باز کنید.  
سپس می‌توانید از دستورهای ساده مارک‌داون برای  
فرمت‌دهی استفاده کنید:

- تیترها را با استفاده از نماد # در ابتدای خط می‌نویسیم:
مثلاً:  
# تیتر اصلی  
## تیتر فرعی  
### تیتر سوم

- بولت‌لیست (لیست نشانه‌دار) با ستاره (*):  
* مورد اول  
* مورد دوم

- عددی‌لیست:  
1. اول  
2. دوم

- متن ضخیم یا بولد با دو ستاره (**):  
**متن بولد**

- متن مورب یا ایتالیک با تک ستاره (*):  
*متن ایتالیک*

- لینک:
[متن لینک](آدرس لینک)

- درج تصویر:  
![](آدرس عکس)  
یا  
![توضیح تصویر](آدرس عکس)

- کد تک‌خطی با ` بک‌تیک:
`نمونه کد`

- کد چندخطی با سه بک‌تیک:
```
کد چندخطی
```

- نقل قول با >  
> این یک نقل قول است.

برای مشاهده نتیجه نوشته‌های Markdown  
می‌توانید در محیطی مانند VS Code افزونه‌ای مثل  
Markdown Preview نصب کنید یا از سرویس‌هایی  
مانند dillinger.io و سایت گیت‌هاب استفاده کنید.

Markdown راهی ساده و سریع است تا بدون نیاز به  
دانش برنامه‌نویسی، متن‌هایی ساختارمند بنویسید و  
به راحتی آنها را با دیگران به اشتراک بگذارید.
